# 时间序列预测Web应用

基于ARIMA模型的股票价格预测与回测平台。

## 功能特性

- 📁 **Excel文件上传**：支持.xlsx格式的时间序列数据上传
- 🔮 **一步向前预测**：使用全部历史数据预测下一个时间点的值
- 📈 **回测检验**：80%训练集+20%测试集的滚动预测评估
- 📥 **结果导出**：导出预测结果到Excel文件
- 📊 **性能指标**：提供MSE、MAE、RMSE等评估指标

## 技术栈

- **后端**：Flask + Python
- **前端**：HTML + CSS + JavaScript
- **数据处理**：pandas, numpy
- **时间序列模型**：statsmodels (ARIMA)
- **评估指标**：scikit-learn

## 数据格式要求

### 输入Excel文件格式

1. **文件类型**：.xlsx 格式
2. **工作表**：仅读取第一个工作表
3. **数据列要求**：
   - **必填列**：名为 `y` 的列，包含单变量时间序列数据
   - **可选列**：名为 `date` 的列，支持任意Excel日期格式或ISO标准日期字符串
4. **数据规则**：
   - 数据行按时间从早到晚排序
   - `y` 列严禁存在缺失值

### 输出Excel文件格式

- 包含测试集对应的全部预测值
- 若原输入包含 `date` 列，输出文件也需同步保留该日期列
- 仅包含一列 `y`，按测试期对应行顺序存放预测值

## API接口

### 上传文件
- **URL**: `/api/upload`
- **方法**: POST
- **参数**: file (Excel文件)
- **返回**: 数据摘要信息

### 一步向前预测
- **URL**: `/api/forecast`
- **方法**: POST
- **返回**: 下一个时间点的预测值

### 回测检验
- **URL**: `/api/backtest`
- **方法**: POST
- **返回**: 预测结果和评估指标

### 导出结果
- **URL**: `/api/export`
- **方法**: POST
- **返回**: Excel文件下载

## 预测方法

本应用使用ARIMA（自回归积分滑动平均）模型进行时间序列预测：

- **模型选择**：ARIMA(2,1,2) 作为主要模型，ARIMA(1,1,1) 作为备选
- **参数说明**：
  - p=2: 自回归阶数
  - d=1: 差分阶数（使序列平稳）
  - q=2: 滑动平均阶数

## 使用说明

1. 启动应用：`python app.py`
2. 打开浏览器访问：http://localhost:5000
3. 上传符合格式要求的Excel文件
4. 点击"执行预测"进行一步向前预测
5. 点击"执行回测"进行滚动预测评估
6. 点击"导出预测结果"下载Excel文件

## 注意事项

- 确保上传的Excel文件包含名为 `y` 的列
- `y` 列不能包含缺失值
- 文件大小限制为16MB
- 回测过程可能需要较长时间，请耐心等待
